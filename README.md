# 🍔 Brasa Burger — Site para Hamburgueria

Site institucional desenvolvido para uma hamburgueria fictícia, com foco em apresentar o cardápio, destacar os diferenciais do estabelecimento e facilitar o contato e realização de pedidos.

O projeto foi desenvolvido como parte do meu portfólio de desenvolvimento web, utilizando tecnologias fundamentais do Front-End.

---

## 📌 Sobre o Projeto

O **Brasa Burger** é um site moderno e responsivo para uma hamburgueria, desenvolvido com uma identidade visual marcante baseada em tons de vermelho, amarelo, branco, marrom e preto.

O objetivo do projeto é criar uma experiência visual profissional, destacando os produtos e direcionando o visitante para o cardápio e os canais de contato.

---

## 🚀 Funcionalidades

- Página inicial com Hero Section
- Imagem de destaque em tela cheia
- Navegação entre as seções do site
- Botão para acessar o cardápio
- Botão para realizar pedido
- Cardápio organizado em blocos
- Seção de hambúrgueres
- Seção de acompanhamentos
- Seção de bebidas
- Seção sobre a hamburgueria
- Blocos com diferenciais da empresa
- Seção de contato
- Informações de horário de funcionamento
- Botões para Instagram e WhatsApp
- Footer com informações do desenvolvedor
- Layout responsivo para dispositivos móveis
- Animações e efeitos de interação
- Efeitos de hover nos botões e cards
- Rolagem suave entre as seções

## 🎨 Identidade Visual

O projeto utiliza uma paleta de cores inspirada em hamburguerias tradicionais e no conceito de comida artesanal.

### Cores principais

- 🔴 **Vermelho:** `#D62828`
- 🟡 **Amarelo:** `#FFC107`
- 🟤 **Marrom:** `#24140E`
- ⚫ **Preto:** `#150A06`
- ⚪ **Branco:** `#FFFFFF`
- 🟠 **Creme:** `#FFF8ED`

A combinação dessas cores proporciona contraste, destaque visual e uma identidade relacionada ao universo de hambúrgueres artesanais.
